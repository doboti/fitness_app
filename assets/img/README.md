## Image Specifications

- **Format**: PNG (recommended) or JPG
- **Aspect Ratio**: 16:9 (horizontal/landscape)
- **Recommended Size**: 1280x720px or higher
- **Background**: Dark or neutral backgrounds work best with the app's dark theme

## Fallback Behavior

If an image is missing, the app will automatically display a placeholder text: "🖼️ Kép hamarosan..."

Once you add the images to this folder, they will automatically appear in the Exercise Library tab.
